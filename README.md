# Weather Now

A simple web app to check the current weather of any city.

## Features
- Search weather by city name  
- Shows temperature, humidity, and weather condition  
- Uses real-time data from OpenWeatherMap API  

## Tech Used
- HTML  
- CSS  
- JavaScript  

## How to Use
1. Enter a city name in the search box.  
2. Click the button to see weather details.  

## API Used
[OpenWeatherMap API](https://openweathermap.org/api)
