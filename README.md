# 🌦️ Weather Now

**Weather Now** is a simple and responsive web app that lets you check the current weather for any city in the world.  
Built using HTML, CSS, and JavaScript with live data from the OpenWeatherMap API.

---

## 🚀 Features
- 🌍 Search weather by city name  
- 🌡️ Displays temperature, humidity, and weather description  
- ⚡ Real-time data using OpenWeatherMap API  
- 📱 Clean and responsive design  

---

## 🛠️ Technologies Used
- **HTML** – Structure  
- **CSS** – Styling  
- **JavaScript (Fetch API)** – Data fetching and interactivity  

---

## 📋 How to Use
1. Enter the name of any city in the search box.  
2. Click the “Get Weather” button.  
3. The current weather details will appear instantly on the screen.  

---

## 🔗 API Used
[OpenWeatherMap API](https://openweathermap.org/api)
